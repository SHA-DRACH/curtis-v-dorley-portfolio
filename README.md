# Hon. Curtis V. Dorley: Portfolio

Profile website for Hon. Curtis V. Dorley, Deputy Minister for Research, Policy & Planning at the Ministry of Gender, Children and Social Protection, Republic of Liberia.

Built with plain HTML5, CSS and JavaScript. No build step is needed. Scroll animations use [AOS](https://michalsnik.github.io/aos/) 2.3.4, loaded from cdnjs.

## Structure

```
index.html        Page content
css/style.css     Styles: light and dark themes, responsive layout (1100 / 900 / 680 / 420px breakpoints)
js/main.js        AOS setup, sticky header, slide-in mobile menu, theme toggle, count-up stats,
                  engagement year filter, quote slider, copy address, back to top
images/           Portrait
```

## Run locally

Open `index.html` in a browser.
