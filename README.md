# Hon. Curtis V. Dorley: Portfolio

Profile website for Hon. Curtis V. Dorley, Deputy Minister for Research, Policy & Planning at the Ministry of Gender, Children and Social Protection, Republic of Liberia.

Built with plain HTML5, CSS and JavaScript. No build step is needed.

## Structure

```
index.html        Page content
css/style.css     Styles, including light and dark themes
js/main.js        Section navigation, mobile menu, theme toggle, engagement filter, copy address, back to top
images/           Portrait
```

## Run locally

Open `index.html` in a browser.
